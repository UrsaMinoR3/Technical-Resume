# David Hernandez — Online Resume

A single-page, responsive resume site for David Hernandez (RPA & AI Developer), built with plain HTML/CSS/JS — no framework, no build step, deploys straight to GitHub Pages.

**Live site:** enable GitHub Pages on this repo (Settings → Pages → Source → `main` branch, `/root`) to get a public URL.

## Structure
```
index.html   — page content (About, Skills, Experience, Education)
style.css    — styling, light/dark theme (auto + manual toggle)
script.js    — dark/light theme toggle logic
```

## Local preview
Just open `index.html` in a browser — no server or build step required.
